# 6.선호도 정렬을 활용한 파인튜닝

선호도 정렬: 지도 학습 파인튜닝은 인간의 선호도와 모델이 마주할 수 있는 다양한 상호작용의 세부적인 차이를 포착하는데 한계를 지닌다. 이러한 한계로 AI 시스템을 인간의 선호도에 맞추기 위한 더 발전된 기술들이 "선호도 정렬" 이라는 포괄적인 용어로 묶여서 불린다.

학습 과정에서 인간 또는 AI의 직접적인 피드백을 반영한다.

직접 선호 최적화(DPO)

#### 데이터 생성 팁

데이터 생성은 지시문 데이터셋과 선호도 데이터셋 모두에서 일관된 방식으로 이루어진다. 프롬프트는 모델의 응답에서 다양성과 복잡성을 유도하도록 설계해야 한다.

결괏값에 변화를 적용하는 것도 합성 선호도 데이터셋을 생성할 때 중요한 요소이다.

#### 선호도 평가

 데이터 평가는 인간 평가자가 수행하거나 LLM을 사용해 자동화 할 수 있다. LLM 평가는 세부적인 평가 기준을 개발하고, 이러한 기준을 명확히 전달하는 프롬프트를 작성한 뒤, 모델이 선택된 답변과 거절된 답변을 선택하도록 하는 과정을 포함한다.

 평가 구현 방식
 - 절대 점수 방식: LLM이 사전에 정의된 기준에 따라 각 응답에 숫자나 점수나 번주형 평가를 할당한다.
 - 쌍별 순위 방식: 두 개의 응답을 제시하고 더 나은 응답을 선택하거나 순위를 매기도록 요청한다.

 LLM 기반 평가에 발생 가능한 편향
 - 위치 편향: 첫 번째 답변 선호
 - 길이 편향: 더 긴 답변 선호
 - 가족 편향: 자신과 동일한 계열의 모델에서 생성한 응답 선호

무작위 배열, 점수의 균형 잡힌 분포를 보여주는 퓨-샷 예제 제공

## 6.3 선호도 정렬

선호도 데이터를 기반으로 모델을 파인튜닝하는 기술

### 6.3.1 인간 피드백을 활용한 강화 학습

인간 피드백을 활용한 강화 학습(RLHF): 강화학습과 인간의 입력을 결합해 모델을 인간의 선호도와 가치에 맞게 조정한다. 핵심은 보상 모델과 정책을 반복적으로 개선하는데 있다
- 보상 모델 학습: 인간의 피드백을 통해 보상 모델을 학습한다.
- 정책 최적화: 학습된 보상 모델을 바탕으로 표준 강화 알고리즘을 사용해 정책을 최적화 한다.
- 반복적 개선: 정책이 개선됨에 따라 새로운 행동이 생성된다.

### 6.3.2 직접 선호 최적화

DPO: 전통적인 RLHF방법에 대한 간소화된 대안 제공
